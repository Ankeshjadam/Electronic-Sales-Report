# Electronic Store Sales Analysis

Data Analysis project on Electronic Store Sales Data using Excel / Power BI.

## 📂 Files in Repository
- `Electronic_Sales_Data.csv` - Sales Dataset
- `Electronic_Sales_Dashboard.pbix` / `Dashboard.xlsx` - Dashboard File

## 📌 Project Overview
Analyzed electronic store sales to understand sales performance, profit, and top products.

## 🧹 Data Cleaning Steps (in Excel / Power Query)
1.  Removed duplicates and null values
2.  Fixed Date format (DD-MM-YYYY)
3.  Cleaned Product Category & Payment Method
4.  Created Calculated Columns - Total Sales, Profit
5.  Standardized Customer and Location names

## 🛠️ Tech Stack
- Advanced Excel / Power Query
- Power BI

## 📊 Dashboard KPIs
- Total Sales, Total Profit, Total Orders
- Sales by Product Category (Laptop, Mobile, TV, Accessories)
- Monthly Sales Trend
- Top 5 Products & Top Customers
- Sales by Payment Method & Region
- Profit Analysis
